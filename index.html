Як працює алгоритм

Введіть дев’ять значень для кожного матеріалу або скористайтеся пакетним вводом.

  1. 01
    Вхідні дані

    П’ять матеріалів, по дев’ять вимірювань від 20° до 100° з кроком 10°.

  2. 02
    Координати точок

    Температура задає положення по горизонталі, значення C·tgδ — по вертикалі. Для однакових значень підпис на осі Y створюється один раз.

  3. 03
    Розведення підписів

    Підписи сортуються за висотою. Алгоритм зберігає їхній порядок і розносить щонайменше на 18 px, щоб зменшити накладання.

  4. 04
    Лінії-виноски

    Близькі мітки групуються; їхні ламані лінії отримують різні точки перегину, щоб зменшити перетини та полегшити читання.

  5. 05
    Результат

    Для кожного матеріалу будується окремий графік із проєкціями та маркерами. Графіки можна зберегти окремо або разом.

Округлення змінює лише підписи значень; вихідні дані для побудови графіка залишаються точними.
